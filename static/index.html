01.1 · AC FUNDAMENTALS

Alternating voltage and sinusoidal quantities

An alternating quantity changes magnitude and reverses direction periodically. A rotating coil in a magnetic field experiences changing flux linkage. By Faraday’s law, an EMF is induced. Its polarity reverses every half-turn, producing alternating voltage.

e(t) = Eₘ sin(ωt + θ)   |   ω = 2πf   |   T = 1/f
Peak value, Eₘ

Maximum instantaneous magnitude of a sinusoidal voltage or current.

RMS value

Equivalent DC value that produces the same heating effect in a resistor.

QuantityFormula for a sine waveMeaning
RMSEₘ / √2 = 0.707 EₘEffective value
Half-cycle average2Eₘ / π = 0.637 EₘMean over one half-cycle
Full-cycle average0Positive and negative halves cancel
Form factorRMS / half-cycle average = 1.11Waveform ratio
Peak factorEₘ / Eᵣₘₛ = 1.414Crest ratio
Example: 230 V RMS has peak value 230 × 1.414 ≈ 325.2 V. At 50 Hz, T = 0.02 s = 20 ms.
01.1 · VECTOR REPRESENTATION

Phasors and phase angle

A phasor represents a sinusoidal quantity by a vector. Vector length represents magnitude; its angle represents phase. Use RMS values unless the problem states otherwise.

φ = (Δt / T) × 360°   or   φ = ωΔt

In phase: phase difference 0°. Quadrature: phase difference 90°. In a series circuit, current is common and is usually selected as the reference phasor.

  1. Draw current I horizontally right.
  2. Draw Vᵣ = IR along I.
  3. Draw Vₗ = IXL upward.
  4. Draw V꜀ = IXC downward.
  5. Supply voltage is the vector sum of all drops.
01.2 · R / L / C RESPONSE

Resistance, inductance and capacitance

Resistor (R)

V and I are in phase. V = IR. Unit: ohm (Ω).

Inductor (L)

Current lags voltage by 90°. XL = 2πfL. Unit of L: henry (H).

Capacitor (C)

Current leads voltage by 90°. XC = 1/(2πfC). Unit of C: farad (F).

Memory rule: resistor, same phase. Inductor, current lags. Capacitor, current leads.
01.3 · SERIES AC CIRCUITS

RL, RC and RLC

In a series circuit the same current flows through every element. Reactance opposes AC; impedance combines resistance and reactance as perpendicular components.

RL: Z = √(R² + XL²) ; tan φ = XL/R
RC: Z = √(R² + XC²) ; tan φ = −XC/R
RLC: Z = √[R² + (XL − XC)²]

If XL exceeds XC, circuit is inductive and current lags. If XC exceeds XL, circuit is capacitive and current leads. When equal, the circuit is at series resonance.

01.3 · AC POWER

Active, reactive and apparent power

P = VI cosφ = I²R   [W]
Q = VI sinφ = I²X   [VAR]
S = VI   [VA]   ;   S² = P² + Q²

Power factor PF = cosφ = P/S = R/Z for a series circuit. Inductive circuits have lagging PF; capacitive circuits have leading PF.

01.4 · SERIES RESONANCE

Resonance and quality factor

At series resonance the inductive and capacitive reactances are equal and cancel. The impedance is minimum and the supply current is maximum.

fᵣ = 1 / (2π√LC)   ;   Q = (1/R)√(L/C)
  • XL = XC
  • Z = R
  • φ = 0° and PF = 1
  • VL and VC are equal in magnitude and opposite in phase
  • Q = XL/R = VL/V = VC/V at resonance
Higher Q means sharper selectivity and greater voltage magnification across L or C.
NUMERICAL METHOD

Reliable sequence for series-circuit problems

1. Convert units to Ω, H, F and Hz.

2. Calculate XL = 2πfL and XC = 1/(2πfC).

3. Find net X = XL − XC.

4. Calculate Z = √(R² + X²).

5. Find I = V/Z and voltage drops.

6. Find φ, PF and powers. Check units.
